## 《MCP 实战手记》（八）· 从"能跑"到"能上线"——无状态 MCP Server 的生产落地清单

本 tag 对应**第（八）篇**，模块 `08-store-ops`，端口 `8088`。

📄 文章：https://blog.csdn.net/weixin_39885962/article/details/166828198

### 这一版解决了什么

迁到 STATELESS 之后，服务能跑但还上不了线。本版把撞上的必答题逐个跑通：

| 问题 | 本版做法 | 代码位置 |
|---|---|---|
| 无状态没有 elicitation，怎么补参 | 工具返回 `inputRequired`，由客户端二次调用补齐 | `service/StoreService.java` + `model/StoreResult.java` |
| 会话数据哪些必须外置 | 抽出 `ContextStore` 抽象，提供 `InMemory` / `Redis` 双实现——同一份代码只差一个配置，双实例下结果完全相反 | `store/ContextStore.java`、`InMemoryContextStore.java`、`RedisContextStore.java` |
| 老客户端 404 / 405 怎么灰度 | 保留旧端点路径，配合无状态端点并存过渡 | `config/McpToolConfig.java` |

### 跑起来

```bash
git clone https://gitee.com/ethanliang2016/mcp-in-action.git   # 国内
# git clone https://github.com/ethanliang2016/mcp-in-action.git # 海外
cd mcp-in-action && git checkout v08
cd 08-store-ops && mvn spring-boot:run    # 端口 8088
```
