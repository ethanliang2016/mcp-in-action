## 《MCP 实战手记》（九）· 生产化 MCP Server 的 6 层安全防护

本 tag 对应**第（九）篇**，模块 `09-store-ops-security`，端口 `8090`。

📄 文章：https://blog.csdn.net/weixin_39885962/article/details/166882799

### 6 层里本版跑通的部分

| 层 | 内容 | 代码位置 |
|---|---|---|
| L1 传输安全 | 生产走 mTLS，在接入层/网关终止；本模块默认关闭以便本地实测 | `application.yml`（注释说明） |
| L2 客户端身份 | `Bearer Token` 校验，不对直接 401 | `security/SecurityFilter.java` |
| L3 用户身份透传 | 提取 `X-User-Id` 放入 `UserContext`（过渡方案，正文已标注边界） | `security/UserContext.java` |
| L4 工具级授权 | 按角色判定工具是否可调用 | `security/StoreRbac.java` |
| L5 限流 | Bucket4j 令牌桶，超限 429 | `security/RateLimiter.java` |
| L6 审计 | 每次调用一条结构化日志（path / method / result / user / costMs） | `security/SecurityFilter.java` |

**令牌不进仓库**：`store.security.token` 取环境变量 `STORE_SECURITY_TOKEN`，默认值仅为占位串。

```bash
STORE_SECURITY_TOKEN=your-real-token mvn spring-boot:run
```

### 跑起来

# git clone https://github.com/ethanliang2016/mcp-in-action.git # 海外

JDK 21+ / Spring Boot 4.0.x / Spring AI 2.0.1 + Spring Security + Bucket4j，全 mock 数据。
